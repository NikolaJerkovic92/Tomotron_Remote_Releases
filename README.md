# Tomotron Remote

Javna stranica za preuzimanje Android i iPhone aplikacija **Tomotron Remote**.

## Android — instalacija i ažuriranje

1. Otvorite [najnovije izdanje](https://github.com/NikolaJerkovic92/Tomotron_Remote_Releases/releases/latest).
2. Otvorite odeljak **Assets**.
3. Preuzmite fajl `Tomotron-<verzija>.apk`.
4. Otvorite preuzeti APK i potvrdite instalaciju.

GitHub nalog nije potreban. Pri prvoj ručnoj instalaciji Android može da zatraži
dozvolu za instaliranje aplikacija iz pregledača. Nova verzija se instalira preko
postojeće i čuva njena podešavanja.

## iPhone — probna verzija

[Preuzmi Tomotron Remote za iPhone 0.1.0](https://github.com/NikolaJerkovic92/Tomotron_Remote_Releases/releases/tag/ios-v0.1.0).

Potreban je iOS 17 ili noviji. IPA fajl je nepotpisan: instalira se preko
Windows/Mac računara uz [Sideloadly](https://sideloadly.io/) i lični Apple
nalog. Besplatan potpis mora da se obnavlja svakih sedam dana. Detaljni
koraci su na stranici izdanja. Preuzimanje u Safari-ju ne instalira aplikaciju.
TestFlight/App Store link još nije dostupan.

Ovo je prva probna iPhone verzija; provera na pravom telefonu i Tomotron
uređajima tek treba da se obavi.

Ovaj repozitorijum sadrži samo javna instalaciona izdanja i kratka obaveštenja o
promenama. Izvorni kod aplikacije nije objavljen ovde.
