# Tomotron Remote

Javna stranica za preuzimanje Android aplikacije **Tomotron Remote**.

## Instalacija i ažuriranje

1. Otvorite [najnovije izdanje](https://github.com/NikolaJerkovic92/Tomotron_Remote_Releases/releases/latest).
2. Otvorite odeljak **Assets**.
3. Preuzmite fajl `Tomotron-<verzija>.apk`.
4. Otvorite preuzeti APK i potvrdite instalaciju.

GitHub nalog nije potreban. Pri prvoj ručnoj instalaciji Android može da zatraži
dozvolu za instaliranje aplikacija iz pregledača. Nova verzija se instalira preko
postojeće i čuva njena podešavanja.

Ovaj repozitorijum sadrži samo javna instalaciona izdanja i kratka obaveštenja o
promenama. Izvorni kod aplikacije nije objavljen ovde.
